# BookMyDesk Multi-Tenancy Framework

## Overview

BookMyDesk Multi-Tenancy Framework is a reusable .NET 8 framework designed to provide tenant resolution, tenant context management, and tenant-aware database access for all BookMyDesk microservices.

The framework follows Clean Architecture principles and is intended to be shared across multiple services.
